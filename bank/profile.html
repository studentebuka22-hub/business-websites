Demo Bank

Version 1.0.0

Welcome to Demo Bank, a banking demonstration application created for educational and portfolio purposes. This application demonstrates secure authentication, account management, transfers, transaction history, customer profiles, and real-time customer support using Firebase. It is intended for learning, demonstrations, UI/UX showcases, and software development practice. No real financial transactions are processed.

✅ Firebase Database
